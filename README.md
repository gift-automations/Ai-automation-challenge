# AI Automation Challenge — 30 Days

A 30-day challenge building real-world AI automation projects, styled as if they were client briefs from Upwork, Fiverr, and LinkedIn.

Each folder = one day = one automation, with a short write-up on the problem, the build, and the impact (time saved, errors reduced, etc).

## Structure
- `day-01-email-classifier/`
- `day-02-order-logger/`
- ...continues through day 30

## Tools used
Zapier, Make, n8n, Python, Claude/GPT API (add/edit as you go)

## Why this exists
Building a public portfolio of automation work to demonstrate real, dated project history for freelance/consulting clients.
